# LeavePro — Employee Leave Management System

A responsive React.js web application for employee leave requests, balance tracking, and manager approvals.

## Tech Stack
- React 18
- React Router v6
- Axios
- Mock REST API (Node HTTP / JSON-Server on port 5000)
- React Toastify
- React Icons
- Custom CSS (Flexbox & Grid, no third-party CSS frameworks)

## Demo Accounts
- **Employee**: `employee@company.com` / `123456`
- **Manager**: `manager@company.com` / `123456`

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the application:
```bash
npm run start:all
```

Or run frontend and backend separately:
```bash
npm run server   # Mock REST API on http://localhost:5000/api
npm start        # React App on http://localhost:3000
```
